Surah Al-Humazah — Ayat 6
نَارُ ٱللَّهِ ٱلْمُوقَدَةُ
(Yaitu) api Allah yang dinyalakan,
Catatan Konteks:

As-Sa'di: api Allah yang dinyalakan, yang bahan bakarnya manusia dan batu.

Ayat ini menjawab pertanyaan di ayat 5: Al-Huthamah itu adalah api Allah. An-Nahhas menjelaskan maksudnya: "yaitu, ia adalah api Allah".

Khilaf dalam QS Al-Humazah
Nar Allah: Badal atau Kalimat Baru?

Kalimat نَارُ اللَّهِ الْمُوقَدَةُ — dengan mubtada' yang dibuang — datang sesudah pertanyaan di ayat 5. Ada dua penjelasan kedudukannya:

  • Badal — Ad-Da'as dkk.: "wal-jumlatu badalun minal huthamah": kalimat ini menjelaskan Al-Huthamah dengan menggantikannya.
  • Musta'nafah (kalimat baru) — kumpulan penulis I'rab Al-Qur'an Al-Karim: "wal-jumlatu musta'nafah": kalimat jawaban atas pertanyaan sebelumnya, tanpa kedudukan i'rab.

Halaman ini mengikuti Ad-Da'as dkk. Ad-Da'as dkk. tidak menyebut Al-Huthamah yang mana; halaman ini menautkannya ke yang terdekat, di ayat 5. Pada kedua pendapat, maknanya sama: Al-Huthamah adalah api Allah.
Makna Leksikal
  • Api.
Status I'rab
  • Mu'rab (berubah akhirnya).
  • Marfu' sebagai khabar bagi mubtada' yang dibuang (Ad-Da'as dkk.: "naru khabarun li-mubtada'in mahdzuf"); tandanya dhammah yang tampak.
  • Mubtada'-nya ditaqdirkan هِيَ, kembali kepada Al-Huthamah (kumpulan penulis I'rab Al-Qur'an Al-Karim: "ay hiya").
Jumlah Tunggal (mufrad); jamaknya نِيرَانٌ.
Gender Perempuan (mu'annats) walaupun tanpa ta' marbuthah — karena itu sifatnya الْمُوقَدَةُ berbentuk perempuan.
Identitas Ma'rifah (tertentu) karena idhafah.
Peran Kata Dalam Ayat

Konsep Gramatikal dalam QS Al-Humazah
Yang Disandarkan kepada Allah: Makhluk atau Sifat?

Apa yang disandarkan (idhafah) kepada Allah ada dua jenis, dan i'rabnya sama — mudhaf dan mudhaf ilaih — tetapi maknanya berbeda:

  • Benda yang berdiri sendiri (a'yan) — seperti نَاقَةَ ٱللَّهِ وَسُقْيَـٰهَا (Asy-Syams: 13) dan api di ayat ini. Ini penyandaran makhluk kepada Penciptanya, untuk memuliakan atau mengkhususkan; ia makhluk, bukan sifat Allah.
  • Sifat yang tidak berdiri sendiri — seperti يَسْمَعَ كَلَـٰمَ ٱللَّهِ (At-Taubah: 6), ilmu Allah, dan kekuasaan-Nya. Ini penyandaran sifat kepada Dzat yang disifati; ia sifat Allah, bukan makhluk.

Pembedaan ini ditegaskan Ibnu Taimiyyah (Al-Jawab Ash-Shahih, Majmu' Al-Fatawa) dan Ibnu 'Utsaimin (Majmu' Fatawa wa Rasa'il). Di ayat ini api disandarkan kepada Allah untuk menunjukkan keagungan dan kedahsyatannya: api yang Allah ciptakan dan nyalakan.
Status I'rab
  • Mu'rab (berubah akhirnya).
  • Majrur sebagai mudhaf ilaih (Ad-Da'as dkk.: "wa lafzhul jalalati mudhafun ilaih"); tandanya kasrah yang tampak.
Identitas Ma'rifah (tertentu) — nama yang paling tertentu.
Peran Kata Dalam Ayat
  • Menjadi mudhaf ilaih bagi نَارُ: api milik Allah, ciptaan-Nya.

ISIM MAF'UL · NA'T · (104:6:3)
الْمُوقَدَةُ
yang dinyalakan
Jenis Kata
  • Isim maf'ul (kata benda yang dikenai perbuatan) dari fi'il أَوْقَدَ — menyalakan.
  • Tsulatsi mazid, musytaq — karena itu memiliki tashrif.
  • Mitsal wawi: huruf pertama akarnya wawu, و - ق - د; pada الْمُوقَدَةُ wawu itu sukun sesudah dhammah, sehingga dibaca panjang.
Pola dan Makna Wazan
  • Fi'il asalnya berwazan أَفْعَلَ – يُفْعِلُ — mazid bab if'aal: أَوْقَدَ – يُوقِدُ; isim maf'ulnya مُفْعَلٌ.
  • Ciri makna bab ini yang tampak: ta'diyah — fi'il asalnya وَقَدَ – يَقِدُ (menyala) lazim; dengan hamzah ia bermakna menyalakan.
  • Tabel seluruh wazan beserta ciri maknanya: Tabel Wazan Fi'il — mazid bab if'aal

RENUNGAN ① Api yang Disandarkan kepada Allah

Api ini disandarkan kepada Allah — penyandaran makhluk kepada Penciptanya, yang menunjukkan keagungannya. Api yang Allah nyalakan tidak dapat dibandingkan dengan api dunia.

Pelajaran bagi kita: siapa yang merendahkan manusia karena merasa tinggi, balasannya api yang Allah sendiri sandarkan kepada-Nya. Takutlah kepadanya dengan menjaga lisan.

RENUNGAN ② Dinyalakan Terus

الْمُوقَدَةُ adalah isim maf'ul: api yang dinyalakan. As-Sa'di: bahan bakarnya manusia dan batu.

Pelajaran bagi kita: azab itu tidak padam dan tidak berhenti; maka hindarilah sebab-sebabnya selagi masih di dunia.
