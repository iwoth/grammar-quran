⌂ Beranda
Surah Al-Buruj — Ayat 5
النَّارِ ذَاتِ الْوَقُودِ
"(Yaitu) api yang mempunyai bahan bakar."
Catatan Konteks:
Ayat ini menjelaskan parit (الْأُخْدُودِ) yang disebut pada ayat 4. Kata النَّارِ berkedudukan sebagai badal (pengganti penjelas) dari الْأُخْدُودِ — menurut pendapat masyhur berupa badal isytimāl (sebab parit itu memuat api), dan sebagian ulama memandangnya badal kull (bila الأخدود dimaknai lubang berapi itu sendiri). Api tersebut disifati ذَاتِ الْوَقُودِ — "yang mempunyai bahan bakar" — menggambarkan api yang besar dan terus dinyalakan dengan bahan bakar melimpah (kayu dan semisalnya). Para mufassir salaf (Ibnu Katsīr, As-Sa'dī, Aṭ-Ṭabarī) menerangkan bahwa para penindas menyalakan api yang berkobar-kobar di dalam parit, lalu melemparkan kaum mukmin ke dalamnya karena keimanan mereka kepada Allah. Struktur sifat pada ayat ini (isim + ذَاتِ + mudhaf-ilaih) serupa dengan pola ayat 1 (السَّمَاءِ ذَاتِ الْبُرُوجِ).
Analisis Tingkat 1 — Kata

Penjelas Parit (Badal)
النَّارِ ذَاتِ الْوَقُودِ
(Yaitu) api yang mempunyai bahan bakar
ISIM · (85:5:1)
النَّارِ
api
Jenis Kata
  • Isim jamid (kata benda asli, bukan turunan/mushtaq) — tidak memiliki tashrif.
  • Nama bagi api; di sini merujuk api dalam parit para penindas.
Status I'rab
  • Majrur karena diakhiri kasrah pada huruf akhir.
  • Majrur sebab menjadi badal dari الْأُخْدُودِ yang majrur — badal mengikuti i'rab mubdal minhu.
Jumlah
  • Tunggal (mufrad).
  • Menunjuk satu api tertentu yang dinyalakan di parit.
Gender
  • Perempuan (mu'annats).
  • Lafaz النَّار diperlakukan mu'annats — karena itu sifatnya pun mu'annats (ذَاتِ).
Identitas
  • Ma'rifah karena diawali ال.
  • Menunjuk api tertentu yang telah maklum dalam kisah.
Peran Kata Dalam Ayat
  • Berperan sebagai badal (pengganti) bagi الْأُخْدُودِ pada ayat sebelumnya — menjelaskan hakikat parit itu: parit berisi api.
  • Sekaligus menjadi man'ut bagi ذَاتِ.
Kaidah badal isytimāl (pengganti penjelas yang mengikuti i'rab mubdal minhu) telah dibahas pada Surah Al-Mā'ūn (107), ayat 5 — https://grammar-quran.com/107-05.html
ISIM · (85:5:2)
ذَاتِ
yang mempunyai
Jenis Kata
  • Isim jamid bermakna "pemilik / yang mempunyai" — bentuk mu'annats (perempuan) dari ذُو.
  • Menjadi mudhaf (bagian pertama idhafah) kepada الْوَقُودِ.
Status I'rab
  • Majrur karena diakhiri kasrah pada huruf akhir.
  • Majrur sebab menjadi na't (sifat) bagi النَّارِ yang majrur — na't mengikuti man'ut dalam i'rab.
Jumlah
  • Tunggal (mufrad).
  • Menyifati satu النَّارِ yang tunggal.
Gender
  • Perempuan (mu'annats).
  • Dipakai ذَاتِ (bukan ذُو) menyesuaikan gender النَّارِ yang mu'annats.
Identitas
  • Ma'rifah karena idhafah kepada isim ma'rifah (الْوَقُودِ).
  • Selaras dengan man'ut-nya (النَّارِ) yang juga ma'rifah — syarat sahnya na't.
Peran Kata Dalam Ayat
  • Berperan sebagai na't (sifat) bagi النَّارِ — menyifati api itu sebagai pemilik bahan bakar.
  • Sekaligus menjadi mudhaf bagi الْوَقُودِ.
Kaidah ذَات (bentuk mu'annats dari al-asmā' al-khamsah ذُو, bermakna "yang mempunyai") telah dibahas pada Surah Al-Masad (111), ayat 3 — https://grammar-quran.com/111-03.html
ISIM · (85:5:3)
الْوَقُودِ
bahan bakar
Jenis Kata
  • Isim jamid — nama bagi bahan bakar (kayu dan semisalnya yang dibakar).
  • Menjadi mudhaf-ilaih (bagian kedua idhafah) bagi ذَاتِ.
Status I'rab
  • Majrur karena diakhiri kasrah pada huruf akhir.
  • Majrur sebab menjadi mudhaf-ilaih (disandarkan kepada ذَاتِ).
Jumlah
  • Tunggal (mufrad) secara lafaz.
  • Bermakna jenis: bahan bakar yang melimpah.
Gender
  • Laki-laki (mudzakkar) secara lafaz.
  • Lafaz وَقُود pada wazan فَعُول.
Identitas
  • Ma'rifah karena diawali ال.
  • Ke-ma'rifah-annya membuat mudhaf sebelumnya (ذَاتِ) turut menjadi ma'rifah.
Peran Kata Dalam Ayat
  • Berperan sebagai mudhaf ilaih bagi ذَاتِ — melengkapi makna kepemilikan.
  • Bersama mudhaf-nya membentuk tarkib idhafah yang menjadi na't bagi النَّارِ.
Kaidah mudhaf-ilaih yang majrur karena idhafah telah dibahas pada Surah Al-Fātiḥah (1), ayat 2 (رَبِّ الْعَالَمِينَ) — https://grammar-quran.com/001-02.html

Rangkaian Frasa Penjelas Parit
Frasa 1 (idhafah — sifat) → Frasa 2 (frasa na'tiyyah — badal bagi parit)
FRASA 1 · IDHAFAH (NA'T)
ذَاتِ الْوَقُودِ
yang mempunyai bahan bakar
Struktur
  • Mudhaf (ذَاتِ) + mudhaf-ilaih (الْوَقُودِ).
  • Idhafah lāmiyyah (bermakna kepemilikan): api yang memiliki bahan bakar.
Makna Frasa Sifat bagi api: api yang mempunyai bahan bakar melimpah sehingga berkobar besar dan terus menyala. Penyebutan sifat ini menggambarkan kedahsyatan siksa yang disiapkan para penindas — sebuah isyarat pengagungan (ta'zhim) atas ganasnya api itu.
4 Karakter Idhafah
  • Tiga karakter dari mudhaf ذَاتِ yang selaras dengan man'ut النَّارِ: majrur (i'rab), tunggal/mufrad (jumlah), dan perempuan/mu'annats (gender).
  • Identitas dari mudhaf-ilaih الْوَقُودِ: ma'rifah (diawali ال) — sehingga ذَاتِ ikut menjadi ma'rifah lewat idhafah.
  • Gabungan empat karakter (majrur · tunggal · perempuan · ma'rifah) seluruhnya selaras dengan النَّارِ — inilah syarat sahnya idhafah ini menjadi na't.
Peran Frasa Dalam Ayat
  • Berperan sebagai na't (sifat) bagi النَّارِ.
  • Berupa na't ghair mufrad (na't berupa frasa idhafah), bukan na't satu kata.
FRASA 2 · FRASA NA'TIYYAH (BADAL)
النَّارِ ذَاتِ الْوَقُودِ
api yang mempunyai bahan bakar
Struktur
  • Man'ut (النَّارِ) + na't berupa idhafah (ذَاتِ الْوَقُودِ).
  • Membentuk murakkab washfi (frasa na'tiyyah) — isim beserta sifatnya dalam satu kesatuan.
Makna Frasa Api yang berbahan bakar melimpah — inilah isi parit (ukhdud) yang disiapkan para penindas. Penyebutan sifat ini menegaskan betapa dahsyat siksa yang mereka timpakan kepada kaum mukmin.
Peran Frasa Dalam Ayat
  • Berperan sebagai badal bagi الْأُخْدُودِ (ayat 4) — badal isytimāl menurut pendapat masyhur.
  • Seluruh frasa berstatus majrur mengikuti mubdal minhu; الْوَقُودِ majrur sebagai mudhaf-ilaih.

Hubungan dengan Ayat Sebelumnya

Ayat ini menjelaskan الْأُخْدُودِ pada ayat 4: النَّارِ ذَاتِ الْوَقُودِ berkedudukan sebagai badal (penjelas) baginya — badal isytimāl menurut pendapat masyhur, karena parit itu memuat api. Api yang disifati "mempunyai bahan bakar" menggambarkan kobaran yang besar dan terus dinyalakan. Kisah berlanjut ke ayat 6–8 yang menggambarkan keadaan para penindas serta sebab mereka menyiksa kaum mukmin.
Kaitan badal dengan mubdal minhu:
قُتِلَ أَصْحَابُ الْأُخْدُودِ ۝ النَّارِ ذَاتِ الْوَقُودِ
"Binasalah para pemilik parit itu — (yaitu) api yang mempunyai bahan bakar."
Analisis Tingkat 4 — Kedudukan dalam Surah
Kedudukan dan peran ayat di dalam keseluruhan surah
Posisi Ayat Ayat kelima Surah Al-Burūj, menjelaskan parit yang disebut pada ayat 4. Surah ini terdiri dari 22 ayat, Makkiyyah.
Hubungan dengan Ayat Sebelumnya Berkedudukan sebagai badal (penjelas) bagi الْأُخْدُودِ pada ayat 4: النَّارِ ذَاتِ الْوَقُودِ menerangkan bahwa parit itu berisi api yang berbahan bakar melimpah.
Hubungan dengan Ayat Berikutnya Ayat 6–8 menggambarkan keadaan para penindas — mereka duduk di tepi parit menyaksikan penyiksaan (إِذْ هُمْ عَلَيْهَا قُعُودٌ) — dan menegaskan bahwa satu-satunya "kesalahan" kaum mukmin adalah keimanan mereka kepada Allah.
Peran dalam Surah Menggambarkan kedahsyatan sarana penyiksaan yang disiapkan para penindas. Detail ini memperbesar celaan atas kezhaliman mereka sekaligus mengagungkan kesabaran kaum mukmin yang rela menghadapi api demi mempertahankan tauhid.

RENUNGAN ① Api Dunia Yang Fana, Api Akhirat Yang Kekal

Para penindas menyalakan api besar berbahan bakar melimpah untuk menyiksa kaum mukmin. Namun api dunia ini, sedahsyat apa pun, akan padam dan berakhir. Sebaliknya, api akhirat yang Allah siapkan bagi para penindas jauh lebih dahsyat dan kekal.

Allah ﷻ menggambarkan api neraka yang bahan bakarnya manusia dan batu: وَقُودُهَا النَّاسُ وَالْحِجَارَةُ "bahan bakarnya manusia dan batu." (At-Tahrīm: 6). Maka siapa yang menzhalimi hamba Allah dengan api, hendaklah ia ingat api yang menanti dirinya.

RENUNGAN ② Keteguhan Iman Di Hadapan Ancaman

Kaum mukmin dalam kisah ini melihat api berkobar di hadapan mereka, namun tetap memilih keteguhan iman daripada kekufuran. Mereka membuktikan bahwa keyakinan kepada Allah lebih mereka cintai daripada keselamatan jasad.

Renungkanlah: ujian yang paling berat sekalipun tidak akan menggoyahkan hati yang benar-benar beriman. Semoga Allah meneguhkan hati kita sebagaimana Dia meneguhkan hati mereka.

RENUNGAN ③ Allah Menyaksikan Setiap Kezhaliman

Sekecil apa pun kezhaliman, hingga sebesar parit api ini, tidak ada yang luput dari penglihatan Allah ﷻ. Rincian yang Allah sebutkan tentang api dan bahan bakarnya menunjukkan bahwa Dia menyaksikan dan mencatat seluruh perbuatan para penindas.

Bagi orang yang teraniaya, ini adalah penghiburan: kezhaliman atasmu disaksikan Allah dan pasti dibalas. Bagi orang yang berbuat zhalim, ini adalah peringatan: tidak ada tempat bersembunyi dari pengawasan-Nya.
